# 洗錢防制與認識客戶政策（AML/KYC Policy）

## 文件資訊
- **文件編號**：AML-POL-001
- **適用範圍**：全行所有業務單位、分行、財富管理中心
- **最近更新**：2024-01-15
- **主管機關依據**：洗錢防制法、資恐防制法、金融機構防制洗錢辦法

---

## 一、政策目的

星河商業銀行（以下簡稱「本行」）致力於防止洗錢、資助恐怖主義及其他金融犯罪行為。本政策依據金融監督管理委員會（金管會）規範制定，確保本行所有業務活動符合法規要求。

---

## 二、客戶盡職調查（CDD）分級標準

### 2.1 簡化盡職調查（Simplified DD）
適用條件：
- 客戶風險評等為「低風險」
- 一般大眾存款帳戶，年交易總額不超過 **50萬新台幣**
- 無涉及高風險國家之資金往來

作業內容：
- 收集基本身分證明文件（國民身分證或護照）
- 基本地址驗證
- 一年一次的客戶資料覆核

### 2.2 標準盡職調查（Standard DD）
適用條件：
- 客戶風險評等為「中風險」
- 一般企業客戶開戶
- 年交易總額 50萬至 3,000萬新台幣

作業內容：
- 收集完整身分資料（身分證、戶籍謄本）
- 驗證資金來源（薪資單、財務報表）
- 最終受益人（UBO）確認（持股 ≥ 25% 之自然人）
- 每兩年覆核一次客戶資料

### 2.3 強化盡職調查（Enhanced DD / EDD）
**強制適用情況**：
- 客戶為**政治公眾人物（PEP）**或其直系親屬
- 來自 FATF 高風險或受監管名單國家的客戶
- **Private Banking 客戶**（AUM ≥ 3,000萬新台幣）
- 客戶風險評等為「高風險」
- 不尋常或複雜的交易結構

EDD 作業要求：
1. 高階主管批准（副總經理級以上）
2. 財富來源書面說明及佐證文件
3. 業務關係目的說明
4. 每年覆核（不可委由自動系統代替）
5. 指定關係經理為第一道防線責任人

## 三、可疑交易申報（STR）

### 3.1 申報觸發條件
下列情況必須於**24小時內**提交可疑交易申報至法令遵循部：

| 情況類型 | 門檻說明 |
|--------|---------|
| 現金交易 | 單筆或累計24小時內超過**50萬新台幣** |
| 不尋常資金往來 | 資金來源不明、與客戶背景不符 |
| 高頻碎額交易 | 疑似結構性交易（化整為零）|
| 境外匯款 | 匯往 FATF 高風險名單國家 |
| PEP相關交易 | 所有非例行性交易 |

### 3.2 申報流程
```
發現可疑 → 填寫STR表單 → 直屬主管確認 → 法令遵循部審核 → 24小時內申報調查局
```

**注意**：任何人不得向客戶透露已提交可疑交易申報（保密義務）。

---

## 四、持續監控機制

- 本行採用**交易監控系統（TMS）**，對所有客戶交易進行即時及事後分析
- 系統每日自動比對 **OFAC制裁名單、Interpol、聯合國制裁名單**
- 高風險客戶每季由法遵部進行人工覆核
- 帳戶異常評分超過閾值時，系統自動凍結並通知法遵人員

---

## 五、違規罰則

員工若違反本政策，依情節輕重：
- **輕微**：書面警告、強制補訓
- **中度**：停職、績效扣分
- **嚴重**：解職、移送司法機關
- **組織層面**：金管會裁罰、吊銷營業執照
